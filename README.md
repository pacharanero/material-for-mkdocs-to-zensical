# material-for-mkdocs-to-zensical

Resources for upgrading Material for Mkdocs sites to Zensical

## Files

- [agents-zensical-upgrade.md](agents-zensical-upgrade.md) — step-by-step checklist for upgrading a Material for MkDocs site to Zensical, designed to be used as a prompt or reference for LLM-driven upgrades
- [.github/workflows/deploy-docs-to-ghpages.yml](.github/workflows/deploy-docs-to-ghpages.yml) — GitHub Actions workflow to build and deploy a Zensical docs site to GitHub Pages

## Usage

Pass `agents-zensical-upgrade.md` to your AI coding agent (e.g. GitHub Copilot, Claude, Cursor) along with your project files and ask it to follow the checklist to perform the upgrade.
